# Compliance map

**Engineering control map, not legal advice.** "Zero compliance risk" cannot be guaranteed by any codebase. This document shows what the package
_removes by design_, what it _evidences_, and what the **organisation must still do**. Legal status below was checked on 2026-11-14 from public
sources; laws change, so re-verify with counsel before each release.

## 1. What the package removes by design

| Risk                                                          | Design response                                   | Evidence                                                                           |
| ------------------------------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Visitor IP sent to Google (Google Fonts)                      | Fonts self-hosted; no third-party origin anywhere | `test/e2e/run.mjs` (zero non-own-origin requests), `verify-package` (banned hosts) |
| Reading/writing the user's device (ePrivacy Art. 5(3) / PECR) | No storage or cookies of any kind                 | e2e storage test, ESLint `no-restricted-globals`, `verify-package`                 |
| Personal data collected by the SDK                            | None collected; no telemetry/analytics            | `PRIVACY.md`, tests above                                                          |
| Third-party transfer mechanics (EU-US DPF dependence)         | No third-party processing in default mode         | n/a by design                                                                      |
| CDN compromise altering what users see                        | Ed25519-signed manifests, pinned keys             | `test/remote.test.ts`                                                              |
| Install-time supply-chain code                                | No lifecycle scripts; one runtime dependency      | `verify-package`                                                                   |
| Inaccessible brand rollout                                    | Contrast guard on every update; CI pair matrix    | `test/schema.test.ts`, `test/tokens.test.ts`                                       |

## 2. Regime-by-regime

| Regime                                                       | Relevance                                                                                                                                                                                                                                       | Status / notes                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **GDPR / UK GDPR**                                           | Applies to the _apps_ using this package. The package itself processes no personal data by default.                                                                                                                                             | Art. 25 (privacy by default) satisfied by default-off `remote`. If `remote` is enabled the manifest host receives IP/UA → needs a legal basis (legitimate interest is typical), notice, and a processor agreement if third-party hosted. Prefer same-domain hosting.                                                           |
| **ePrivacy (Art. 5(3)) / UK PECR**                           | Storing/reading data on the user's device needs consent unless strictly necessary                                                                                                                                                               | Package stores nothing.                                                                                                                                                                                                                                                                                                        |
| **EU-US Data Privacy Framework**                             | Matters only if a US-based provider hosts the manifest                                                                                                                                                                                          | The General Court upheld the DPF on 3 Sep 2025; an appeal (C-703/25 P) is pending, so avoid dependence. Default mode has none.                                                                                                                                                                                                 |
| **India DPDP Act 2023 / Rules 2025**                         | Applies to data fiduciaries operating the apps                                                                                                                                                                                                  | Rules notified Nov 2025; consent-manager provisions from 13 Nov 2026; **main obligations from 13 May 2027**; SPDI Rules (IT Act s.43A) continue until then. The package is out of scope by default; if `remote` is enabled, IP-bearing logs are personal data → notice, security safeguards, retention limits, breach process. |
| **CERT-In Directions (Apr 2022)**                            | Org-level incident reporting & log retention                                                                                                                                                                                                    | Verify current requirements with counsel; process-level, not code-level.                                                                                                                                                                                                                                                       |
| **EU Cyber Resilience Act**                                  | HexaData's **servers/workstations** are likely "products with digital elements" (manufacturer duties: vulnerability handling, reporting to ENISA/CSIRT). Reporting obligations have applied since 11 Sep 2026; full application is 11 Dec 2027. | This npm package is probably **not** a product in scope, but `SECURITY.md` + SBOM (release workflow) are cheap alignment. Confirm with counsel.                                                                                                                                                                                |
| **EU Accessibility Act / EN 301 549 / ADA / India RPwD Act** | Customer-facing digital services                                                                                                                                                                                                                | Contrast is enforced to WCAG 2.2 AA (`ACCESSIBILITY.md`). The app must handle the rest.                                                                                                                                                                                                                                        |
| **Fonts (SIL OFL 1.1)**                                      | Redistribution terms                                                                                                                                                                                                                            | Licence texts copied into `dist/licenses/` by `build:fonts` (fails if absent); `NOTICE` lists them. Check each font's Reserved Font Name clause before subsetting/modifying (currently shipped unmodified from fontsource).                                                                                                    |
| **Trademark / brand licence**                                | Brand Kit v1.0: assets may not be used without written authorisation from HexaData or Esconet Technologies Limited                                                                                                                              | `LICENSE` is proprietary/UNLICENSED and the package is `restricted` by default. **Obtain written sign-off before making it public.** Logos are deliberately _not_ included.                                                                                                                                                    |
| **CCPA/CPRA, COPPA, LGPD etc.**                              | Only if personal data is processed                                                                                                                                                                                                              | Not triggered by the package.                                                                                                                                                                                                                                                                                                  |

## 3. Organisation tasks the repo cannot do (checklist)

- [ ] Appoint/confirm a DPO or privacy lead; have counsel review `PRIVACY.md` and this map.
- [ ] Add the manifest host (if used) and npm/GitHub to the **Record of Processing Activities / vendor register**; sign DPAs where a third party processes IPs.
- [ ] Decide `remote` on/off per product and region; document the legal basis and update privacy notices if on.
- [ ] Access-log policy for the manifest host (retention ≤ 30 days or pseudonymised).
- [ ] Incident-response runbook incl. signing-key compromise (see `SECURITY.md`), DPDP/GDPR breach clocks, CERT-In reporting.
- [ ] Production signing keys in KMS/HSM; npm 2FA; protected `release` environment; branch protection + required reviews on `tokens/` and `src/core/remote.ts` (see `CODEOWNERS`).
- [ ] Written authorisation from Esconet/HexaData for distribution; decide public vs private registry; finalise `LICENSE`.
- [ ] Publish `security.txt`; set the real security contact in `SECURITY.md`.
- [ ] Commit `package-lock.json`; pin GitHub Actions to commit SHAs; enable Dependabot alerts and secret scanning.
- [ ] Accessibility: run axe + manual audits on products; resolve the grey-text/accent-text design decisions (`docs/AMENDMENT-REQUEST.md`).
